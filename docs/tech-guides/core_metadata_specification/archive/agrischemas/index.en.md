# FAIRagro Agrischemas Changelog

All notable changes to FAIRagros Agrischemas will be documented on this page.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.1.0] - 2026-11-03

### Changed
- Changed the name of "soil texture" property to "soil texture type" (see issue https://github.com/fairagro/agri-wg-bioschemas/issues/34)
- Simplified definition of "soil texture" property (see issue https://github.com/fairagro/agri-wg-bioschemas/issues/34)
- Changed definition of "soil pH" (see issue https://github.com/fairagro/agri-wg-bioschemas/issues/35)
- Simplified definition of "bulk density" property (see issue https://github.com/fairagro/agri-wg-bioschemas/issues/36)
- Changed semantic concept of "bulk density" property from http://aims.fao.org/aos/agrovoc/c_7167 to http://purl.obolibrary.org/obo/ENVO_00010005 (see issue https://github.com/fairagro/agri-wg-bioschemas/issues/36)
- Changed unit of "total carbon" property to from "percent" to "g x kg⁻¹"

### Deprecated
- Marked "available water content" property for deprecation due to not fitting with findability focused goal of Agrischemas (see issue https://github.com/fairagro/agri-wg-bioschemas/issues/37)


## [1.0.0] - 2025-12-22

### Added
